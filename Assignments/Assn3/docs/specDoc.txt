def probabilities(qc, qbits, cbits):
    """
    -- probabilities of classical register values, with ancillae
    where:
        qc = Qiskit quantum circuit with no classical bits (unmeasured)
        qbits = list of qubit wire numbers to measure
        cbits = list of classical bits the qubits are mapped to
    assumes:
        qc.num_clbits == 0
        len(qbits) == len(cbits) == m
        cbits is a permutation of range(0,m)
    returns:
        list of measured register value frequencies, indexed by register value
    """

Implementation Requirements:
---------------------------
[ ] Get unitary matrix and compute full state probabilities
[ ] Implement mapping function: I = map(J)
[ ] Sum probabilities for all J that map to same I
[ ] Handle arbitrary qubit-to-cbit mappings
[ ] Return list of length 2^m (not 2^n)

Key Algorithm (Pseudocode):
---------------------------
1. Get full probabilities (as in probabilities0)
2. Initialize: cprob = [0] * (2**m)
3. For each quantum state J in range(2**n):
   a. Calculate classical register value I:
      I = 0
      for i in range(m):
          if J & (2**qbits[i]) != 0:
              I += 2**cbits[i]
   b. Accumulate probability:
      cprob[I] += qprob[J]
4. Return cprob

Bit Mapping Logic:
-----------------
- Quantum state |J⟩n has bits: Jn-1...J1J0
- Classical register I has bits: Im-1...I1I0
- Mapping rule: Ic(i) = Jq(i) for all i
- Example: qbits=[1,2], cbits=[1,0]
  * I1 = J1 (qubit 1 → classical bit 1)
  * I0 = J2 (qubit 2 → classical bit 0)

--------------------
[ ] Correctly implements bit mapping
[ ] Handles permutation of cbits
[ ] Sums probabilities for equivalent measurements
[ ] Returns list of length 2^m
[ ] Total probability sums to 1.0

================================================================================
COMMON PITFALLS AND TIPS
================================================================================

Binary/Hex Conversion:
---------------------
- Qiskit returns hex strings like '0x2'
- Convert using: int('0x2', 16) = 2
- Handle missing values (zero frequency outcomes)

Bit Ordering:
------------
- Qiskit uses little-endian for classical bits
- Qubit |bn-1...b1b0⟩ has b0 as rightmost
- Test with known simple circuits first

Ancilla Handling:
----------------
- Ancillae are unmeasured qubits
- They still affect the quantum state
- Only measured qubits contribute to classical register

Probability Calculations:
------------------------
- Use np.abs(amplitude)**2 for probability
- Watch for numerical precision issues
- Verify probabilities sum to 1.0
